# платформа подготовки к огэ

статический сайт (github pages) + база supabase. всё бесплатно.

## что где лежит

- `index.html`, `css/`, `js/` — сам сайт
- `data/bank.json` — 1340 задач по информатике (без ответов, их видят все)
- `data/img/` — картинки к задачам, `data/files/` — файлы к заданиям 11–14
- `data/rubrics.json` — критерии для 13–16
- `supabase/schema.sql` — база: таблицы, права доступа, проверка ответов
- **`keys.json` — ответы. в репозиторий не класть!** хранить только у себя.

## 1. supabase (10 минут)

1. supabase.com → **new project**, регион Frankfurt или Stockholm, пароль базы сохрани.
2. слева **SQL Editor** → **new query** → вставь весь `supabase/schema.sql` → **Run**. должно быть «Success».
3. **Authentication → Sign In / Providers → Email**: выключи **Confirm email**, иначе ученикам придётся подтверждать почту (письма supabase иногда уходят в спам).
4. **Project Settings → API**: скопируй **Project URL** и ключ **anon / publishable** (не `service_role`!) в `js/config.js`.

## 2. файлы, которых нет в архиве

положи в `data/files/`:
- свой `DEMO_12.zip` (к заданию 11) — так и назови `DEMO_12.zip`
- свой `DEMO-12__9_.rar` (к заданию 12) — переименуй в `DEMO-12.rar`

архивы к 13.1 лежат в отдельном архиве `files13.zip` — распакуй его содержимое в `data/files/13/`.

## 3. github pages

файлов много (около тысячи картинок), через сайт github их загружать неудобно — проще **GitHub Desktop**:

1. github.com → **new repository**, имя например `oge`, public.
2. GitHub Desktop → **clone** этот репозиторий → скопируй в его папку всё содержимое `platform` (кроме `keys.json`) → **commit** → **push**.
3. на github: **Settings → Pages → Source: Deploy from a branch → main / root → Save**. через минуту сайт будет по адресу `https://ТВОЙ-НИК.github.io/oge/`.

## 4. первый вход

1. открой сайт → «зарегистрироваться» своей почтой.
2. supabase → SQL Editor → выполни (подставь свою почту):
   ```sql
   update public.profiles set role = 'teacher'
    where id = (select id from auth.users where email = 'твоя@почта');
   ```
3. обнови страницу — откроется панель учителя.
4. **настройки → загрузить банк задач** → выбери `keys.json` → «загрузить». займёт около минуты. повторять можно сколько угодно, дублей не будет.

## 5. ученики

- даёшь ученику ссылку, он регистрируется сам.
- он появится у тебя в «ученики → новые ученики»: нажми «+ информатика» — у него откроются задания.
- домашка и пробники назначаются на странице ученика или во вкладке «пробники».

## как устроена проверка

- задания 1–12: ответ сверяется в базе (регистр, «ё», запятая/точка и пробелы не важны). несколько верных вариантов в ключе — через `|`.
- 13–15: ученик прикрепляет файл, ты ставишь балл во вкладке «проверка» по чек-листу.
- 16: ученик вставляет код; кнопка «прогнать тесты» запускает его прямо в твоём браузере и подсказывает балл.
- ученики не видят ответов: ключи лежат в отдельной таблице, доступной только учителю.

## если что-то сломалось

- «профиль не найден» — не выполнен `schema.sql`.
- белая страница — открой консоль браузера (F12), скорее всего ошибка в `config.js`.
- `schema.sql` можно выполнять повторно — данные не сотрутся.
